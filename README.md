## 🌟 Introduction & Studio Overview

**The Creative Edit** is a multidisciplinary digital design and creative technology studio. We partner with ambitious startups, luxury brands, media houses, and innovative enterprises to deliver tailored digital experiences that marry editorial sophistication with high-performance web engineering.

### Core Disciplines:
- **Creative Direction & Editorial Design**: Sophisticated typography, art direction, and digital publications.
- **Brand Identity & Strategy**: Distinctive visual identities, design languages, and guidelines.
- **Full-Stack Web Engineering**: Modern, accessible, sub-second web platforms powered by Astro, React, and Tailwind CSS.
- **Design Systems & UI/UX**: Enterprise token architectures, reusable component libraries, and WCAG AAA compliance.
- **Motion & Interactive Web**: Fluid micro-interactions, responsive 3D web elements, and kinetic animations.

## 💻 Local Development & Quick Start

### Prerequisites
- **Node.js**: `v18.17.1` or higher installed
- **npm**, **pnpm**, or **yarn**

### 1. Installation
Clone the repository or navigate to the project directory:

```bash
cd The-Creative-Edit
npm install
```

### 2. Start Local Development Server
Launch the Astro development server with hot-reloading:

```bash
npm run dev
```

Visit `http://localhost:4321` in your browser to view the live site.

### 3. Production Build
Compile static assets and verify type safety:

```bash
npm run build
```

### 4. Preview Build
Preview the production bundle locally:

```bash
npm run preview
```

## ⚙️ Configuration & Customization

The entire website is managed through a single, type-safe configuration file: **[`src/config.ts`](./src/config.ts)**.

### Customizing Brand & Contact Details:

```typescript

  name: "The Creative Edit",
  title: "Creative Studio & Digital Design Agency",
  description: "Official website of The Creative Edit...",
  accentColor: "#4f46e5", // Primary theme color
  
  // Social Channels
  social: {
    email: "hello@thecreativeedit.com",
    linkedin: "https://linkedin.com/company/thecreativeedit",
    twitter: "https://x.com/thecreativeedit",
    github: "https://github.com/thecreativeedit",
    instagram: "https://instagram.com/thecreativeedit",
  },

  // Primary & Alternative Contact Matrix
  contact: {
    primary: {
      label: "Primary Studio",
      locationName: "New York HQ",
      address: "Studio 402, 180 Varick Street, SoHo, New York, NY 10014, USA",
      email: "hello@thecreativeedit.com",
      phone: "+1 (555) 234-5678",
      hours: "Monday – Friday: 9:00 AM – 6:30 PM EST",
    },
    alternative: {
      label: "Alternative / European Hub",
      locationName: "London Creative Lab",
      address: "Level 3, 24 Greville Street, Farringdon, London EC1N 8SS, UK",
      email: "projects@thecreativeedit.com",
      phone: "+1 (555) 987-6543",

    },
    support: "support@thecreativeedit.com",
  },
  
  // Skills, Projects, Experience, and Education...
};
```

Updating any field in `config.ts` will automatically reflect across the Hero, Navigation, About, Projects, Experience, Contact, and Footer components.

## 📦 Build & Deployment

The static output generated by `npm run build` in the `dist/` directory can be deployed to any static web hosting provider:

- **[Vercel](https://vercel.com/)**: Connect the GitHub repository; Vercel automatically detects Astro.
- **[Netlify](https://www.netlify.com/)**: Set build command to `npm run build` and publish directory to `dist/`.
- **[Cloudflare Pages](https://pages.cloudflare.com/)**: Framework preset: `Astro`, output directory: `dist`.
- **[GitHub Pages](https://pages.github.com/)**: Push to your repository and deploy via GitHub Actions.
